Number of images (number of jpg files): 6169

Number of annotations (number of xml files): 6169

Number of annotations (number of txt files): 6169

Label category count: 1

Label category name: ["Buds"]

Number of boxes and the number of images occupied by each category:

Buds Frames = 35373, Pictures Taken = 6169

Total frame count: 35373

Image resolution: 676x760

Using labelImg:

Annotation rules: Draw a rectangle around the category.

Important Notice: The dataset does not have separate training, validation, and test sets; you need to partition them yourself.

Special : This dataset does not guarantee the accuracy of the trained models or weight files.
